## 🌟 Flagship products

### 📈 [Glitch Executor](https://glitchexecutor.com/) — [glitchexecutor.com](https://glitchexecutor.com/)
A prop-firm trading dashboard. Track every prop-firm challenge in real time — drawdown, targets, daily limits — across all your connected accounts in one view, with a strategy builder and a backtester that's aware of each firm's rule set. One dashboard for every connected account; build a strategy, then test it against the exact rules of the firm you're trading.

### 🔮 [Vediq](https://vediqastrology.com/) — [vediqastrology.com](https://vediqastrology.com/)
A Vedic astrology app. Accurate birth-chart calculation and personalized daily guidance, grounded in classical jyotish, delivered in a clean mobile experience.

### 📜 [Clause Lens](https://clauselens.online/) — [clauselens.online](https://clauselens.online/)
Scan any lease or contract and get a plain-English, statute-grounded read in seconds: the risky clauses, what the law says, and what to ask before you sign.

## 🗄️ Archived — Mesh Pilot

**Mesh Pilot** (an open agent mesh + a proprietary orchestration brain for digital marketing) is **no longer active as a product**. The six specialist agents built for it stay public and MIT-licensed — useful on their own.

| Agent | What it does |
|---|---|
| [`ai-voice-agent`](https://github.com/Nuraveda-Labs/ai-voice-agent) | LiveKit-based conversational voice (outbound + inbound). |
| [`ai-seo-agent`](https://github.com/Nuraveda-Labs/ai-seo-agent) | Automated SEO audit, structured-data injection, on-page optimization. |
| [`ai-ads-agent`](https://github.com/Nuraveda-Labs/ai-ads-agent) | Cross-platform ad ops — ROAS, attribution, HITL-gated spend. |
| [`ai-social-agent`](https://github.com/Nuraveda-Labs/ai-social-agent) | Multi-brand social content ops, short-form video, ORM guardrails. |
| [`ai-sales-agent`](https://github.com/Nuraveda-Labs/ai-sales-agent) | Sales pipeline — outreach, qualification, follow-up. |
| [`ai-ugc-agent`](https://github.com/Nuraveda-Labs/ai-ugc-agent) | UGC generation pipelines for D2C and brand work. |
| [`app-docs`](https://github.com/Nuraveda-Labs/app-docs) | Mesh Pilot agent documentation (archived). |

## 🧩 Open-source tooling & projects

| Project | What it is |
|---|---|
| [`linkedin-ads-mcp`](https://github.com/Nuraveda-Labs/linkedin-ads-mcp) | MCP server for the LinkedIn Marketing API — campaigns, analytics, creatives from any MCP client. [`pip install linkedin-ads-mcp`](https://pypi.org/project/linkedin-ads-mcp/) |

| [`shopify-agentic-seo-app`](https://github.com/Nuraveda-Labs/shopify-agentic-seo-app) | Open framework for an agentic SEO app for Shopify — audits, JSON-LD automation, `llms.txt` / AI-search readiness. |
